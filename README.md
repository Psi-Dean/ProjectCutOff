# 📘《砍价游戏 核心玩法规则 v0.1》

---

# 一、游戏目标

玩家在**最多10回合内**，通过出牌降低商品价格。

## 胜利条件

满足以下任一条件：

1. 商品价格  **\= 0**

   - 立即胜利
2. 商品价格  **≤ 玩家当前现金**

   - 玩家可选择：

     - 直接付款 → 扣除现金并胜利
     - 继续砍价 → 游戏继续

---

## 失败条件

1. 第10回合结束时：

   - 商品价格仍高于玩家可支付范围
2. 第10回合结束时：

   - 商品价格 ≤ 可支付范围，但玩家现金不足支付

---

# 二、核心资源

| 资源     | 说明                   |
| ---------- | ------------------------ |
| 商品价格 | 当前需要砍价的目标数值 |
| 玩家现金 | 用于直接付款           |
| 手牌     | 玩家每回合可使用的卡牌 |
| 回合数   | 最大为10回合           |
| 状态效果 | 持续影响游戏规则       |

---

# 三、卡牌使用规则

- 每回合玩家**最多使用3张卡牌**
- 每张卡可选择：

  - 使用
  - 跳过
- 卡牌效果类型：

  - 数值类（改变价格）
  - 状态类（加入持续效果）

---

# 四、状态系统

## 状态生效规则

- 状态在获得后 **立即加入生效状态列表**
- 状态立即开始影响游戏

## 状态持续时间

- 每个状态具有“剩余回合数”
- 在**回合结束时统一 -1**
- 剩余为0时移除

## 状态作用方式

- 状态在对应阶段**影响行为结果**

  - 例如：

    - 阻止涨价
    - 修改数值结果
    - 触发额外效果

---

# 五、回合流程

---

## 1️⃣ 回合开始

1. 抽牌：

   - 第1回合：抽6张
   - 之后：每回合抽3张
2. 奸商预告规则：

   - 第1回合：不显示
   - 第2回合开始：启用“分阶段预告机制”

---

## 2️⃣ 玩家阶段

玩家最多执行3次出牌操作。

---

### ▶ 第1张牌

1. 玩家出牌或跳过
2. 结算效果：

   - 数值变化 或 状态加入
3. 若价格变化：

   - **立即检查胜利/付款条件**
4. 显示奸商提示：

   - 「思考中」

---

### ▶ 第2张牌

1. 玩家出牌或跳过
2. 结算效果
3. 若价格变化：

   - **立即检查胜利/付款条件**
4. 显示奸商提示：

   - 「本回合可能行动」

---

### ▶ 第3张牌

1. 玩家出牌或跳过
2. 结算效果
3. 若价格变化：

   - **立即检查胜利/付款条件**

---

## ▶ 手牌上限管理

- 若手牌数量 \> 15：

  - 玩家必须弃牌
  - 弃至 ≤15

---

## 3️⃣ 奸商阶段

1. 展示奸商本回合行动
2. 结算逻辑：

   ```text
   若存在状态效果 → 状态优先影响结果
   否则 → 正常执行奸商行为
   ```
3. 执行行为：

   - 价格变化 或 状态变化
4. 展示结果

---

## 4️⃣ 回合结束

---

### ▶ 胜负判断

#### 胜利

- 价格 \= 0 → 立即胜利
- 价格 ≤ 玩家现金 → 触发选择：

  - 直接付款 → 胜利
  - 继续砍价 → 进入下一回合

---

#### 失败

- 第10回合结束仍未达标
- 或无法支付

---

### ▶ 状态结算

- 所有状态持续时间 -1
- 为0则移除

---

### ▶ 进入下一回合

---

# 六、奸商预告机制（关键特色）

奸商行为不会直接提前完全展示，而是**分阶段揭露**：

| 时机      | 信息               |
| ----------- | -------------------- |
| 第1张牌后 | 思考中             |
| 第2张牌后 | 显示可能行动       |
| 第3张牌前 | 玩家已获得决策信息 |

👉 第3张牌 \= **策略决策点**

---

# 七、设计核心体验

本游戏的核心体验为：

> **前两张牌用于试探信息，第三张牌用于策略应对，在风险与收益之间做选择。**
